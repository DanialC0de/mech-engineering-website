## 📖 دربارهٔ پروژه

این وب‌سایت بستری برای **ارتباط مؤثر میان استادان، دانشجویان و انجمن علمی مکانیک** فراهم می‌کند.  
امکانات اصلی شامل:

- اطلاع‌رسانی رویدادهای علمی، کارگاه‌ها و همایش‌ها
- ثبت‌نام حضور دانشجویان در رویدادها
- نمایش دستاوردهای پژوهشی و پروژه‌های دانشجویی
- پیشنهاد رویداد و مقاله توسط اساتید 
- درخواست عضویت و همکاری با انجمن

این پروژه با هدف تسهیل ارتباطات و افزایش همکاری‌های علمی در محیط دانشگاه طراحی شده است.

---

## 🌿 برنچ‌های پروژه

| برنچ   | توضیح                                                                 |
|--------|------------------------------------------------------------------------|
| `main` | نسخهٔ پایدار قبلی (نگهداری می‌شود، اما توسعهٔ جدید در آن اعمال نمی‌شود) |
| `new`  | برنچ اصلی توسعه، آخرین تغییرات و ویژگی‌ها در این برنچ قرار دارند       |
| `dev`  | (در صورت وجود) برنچ توسعهٔ داخلی برای ادغام تغییرات پیش از انتقال به `new` |

> **توصیه:** برای همیشه از برنچ `new` استفاده کنید.

## 🧰 تکنولوژی‌ها و کتابخانه‌ها

### بک‌اند (Backend)

- **[Django](https://www.djangoproject.com/)** — فریم‌ورک اصلی وب
- **[Django REST Framework](https://www.django-rest-framework.org/)** — ساخت APIهای RESTful
- **[django-cors-headers](https://github.com/adamchainz/django-cors-headers)** — مدیریت درخواست‌های Cross-Origin
- **[django-filter](https://django-filter.readthedocs.io/)** — فیلترسازی پیشرفته برای APIها
- **[python-decouple](https://github.com/HBNetwork/python-decouple)** — جداسازی تنظیمات حساس از کد
- **[django-allauth](https://github.com/pennersr/django-allauth)** — احراز هویت جامع (ورود با ایمیل و شبکه‌های اجتماعی)
- **[Celery](https://docs.celeryq.dev/)** — مدیریت تسک‌های غیرهمزمان (در صورت نیاز)

> 📌 لیست بالا بر اساس معمول پروژه‌های Django پیشنهاد شده است. برای مشاهدهٔ وابستگی‌های دقیق، فایل `requirements.txt` را بررسی کنید.

### فرانت‌اند (Frontend)

- **HTML5** — ساختار صفحات
- **CSS3 (خالص)** — استایل‌دهی سفارشی (بدون استفاده از Bootstrap یا فریم‌ورک‌های مشابه)
- **JavaScript (ES6)** — تعاملات پویا و ارتباط با API
